# C-Drive-Migrator

C盘大软件迁移工具 - 将大型软件从C盘迁移到其他磁盘，释放C盘空间。

## 功能

- 自动扫描C盘大型软件
- 安全迁移到其他磁盘
- 保持软件正常运行

## 下载

[下载最新版本](https://github.com/huanghoxy-stack/C-Drive-Migrator/releases/latest)

## 使用方法

1. 下载 `SoftwareMigrator.exe`
2. 右键 → 以管理员身份运行
3. 选择要迁移的软件和目标磁盘
4. 点击迁移

## ⚠️ 下载被拦截？

由于未签名，浏览器可能拦截：
- **Edge**: 点 `...` → 保留 → 仍要保留
- **Chrome**: 点保留 → 仍要下载

或 PowerShell 运行：
```powershell
Unblock-File -Path ".\SoftwareMigrator.exe"
```
